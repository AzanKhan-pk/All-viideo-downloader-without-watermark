FAQ

Does it support all yt-dlp sites?

The backend uses the installed yt-dlp extractor set rather than a manually limited list. yt-dlp currently includes a very large number of extractors, but individual sites can be temporarily broken, restricted, require authentication, or change their technology.

Does 4K always work?

No. 4K is only possible when the source provides a compatible 2160p format. The downloader should not fake a 4K source when one is not available.

Will the website automatically refresh?

No. The website checks for new versions in the background, but it will only reload when a newer website version is actually published. It will not continuously refresh itself.

What content can I download?

Only download media you have permission to save, public-domain material, or content whose terms authorize downloading. Do not bypass DRM or access private material without permission.
